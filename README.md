# VincereHandball-Grabadora
App de escritorio para grabar clips de entrenamiento de balonmano desde cámaras USB y móviles. Archiva por equipo, jugador y ejercicio. Admite varias cámaras a la vez y una pantalla para el segundo monitor.  Python + OpenCV se encargan de las cámaras y del disco. La interfaz es web (HTML/CSS/JS) dentro de una ventana nativa con pywebview
